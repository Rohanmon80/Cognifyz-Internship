# Cognifyz Web Development Internship

This repository contains my web development projects created as part of the Cognifyz Web Development Internship.

## Projects

### Project 1: Image Gallery and Slideshow

An image gallery website featuring a responsive image grid and an interactive slideshow.

**Features**

* Image gallery layout
* Image slideshow with navigation controls
* Full-screen image preview
* Responsive design

**Technologies:** HTML, CSS, JavaScript

### Project 2: Responsive Cards

A responsive technology showcase featuring cards arranged using responsive layouts.

**Features**

* Responsive card grid
* Technology-themed content
* Card images and descriptions
* Mobile-friendly layout

**Technologies:** HTML, CSS, Bootstrap, Bulma

### Project 3: Responsive Website

A responsive digital agency website with navigation, service information, and contact sections.

**Features**

* Responsive layout
* Hamburger navigation menu
* Services section
* About and contact sections

**Technologies:** HTML, CSS, JavaScript

### Project 4: Internship Landing Page

A landing page designed to present internship program information in a clear and organized layout.

**Features**

* Internship program overview
* Program cards
* Benefits section
* Call-to-action section
* Responsive navigation

**Technologies:** HTML, CSS, JavaScript

## How to Run the Projects

1. Download or clone this repository.
2. Open the desired project folder.
3. Open `index.html` in a web browser, or use the Live Server extension in Visual Studio Code.
4. Explore the website and test its features.

## Repository Structure

Each project is maintained in its own folder with its source files and any required assets.
